## 完成情况

12/12 候选、12/12 baseline 精度检查通过；12/12 同卡配对性能测试完成。另对 GDN 长序列追加一次完整复测，三个角色均通过。没有修改算子源码。

每个独立角色检查 seed 0、42，各重复 10 次并在计时后复验；每份记录含 22 条检查。冻结输入不会因 seed 变化必然生成新数据，不能将这两组计为独立随机数据集。配对角色对两个端点各重复检查并复验。

性能使用独占 B200，同进程、同卡、相同输入，平衡交替 AB/BA；每轮 50 对，共 3 轮。下列时间是各轮 cold-L2 kernel span 中位数的均值，包含 kernel 间空隙，不含完整 Python 端到端成本。加速比 = baseline / 候选，大于 1 表示候选更快。

## GDN 长序列追加复核

`t8192_n20` 首测候选三轮约 187.232、138.448、124.784 µs，baseline 约 126 µs。追加复测候选三轮 125.281、124.977、124.767 µs，baseline 均值 125.973 µs，候选均值 125.008 µs，比值 1.008×。保留全部六轮等权汇总，比值为 0.916×。

首测原始 trace 显示 kernel 间空隙和重叠程度存在变化。例如一条候选记录 span 为 198.048 µs、busy 为 140.640 µs，两个 kernel 之间存在约 57.408 µs 空隙。现有证据不足以唯一确定波动根因，不应挑选最快一轮宣称稳定提速。两次任务前后频率检查均为 1965 MHz，未发现该项测量时的明显降频证据。

DSA 中等长度和 MoE t901 分别约 0.781×、0.904×，稳定慢于对应 baseline；GDN 长序列性能不稳定，追加复测接近持平。DSA 短序列三轮跨越 1，约 1.029× 只能视为接近持平，未建立统计显著的优势。

## 精度、环境与频率边界

- DSA 检查输出及 LSE；GDN 检查输出及新状态；FA4 检查 dq/dk/dv，使用独立 TriDao 梯度参考与原有比较准则。
- MoE 使用原有规范：atol=1、rtol=0.3，匹配比例至少 90%。通过不等于每个元素都满足更严格误差阈值。详细误差保存在原始结果中。
- DSA/GDN/MoE 使用冻结官方输入及对应 baseline；源码指纹与固定版本逐项核对。baseline 指纹、输入路径及运行环境见记录和入口脚本。
- DSA/GDN/MoE 采用已有 DSL 4.6 环境；GDN t5709 三个角色统一使用 CUDA 12.9，解决 CUDA 13.2 环境下的 driver entry point 错误。
- FA4 GQA 使用已有 fa4deps + DSL 4.5.2 环境；MHA/varlen 使用 fa4b32 快照 + DSL 4.6.2。每个 shape 的候选和 baseline 均在同一环境重新配对测量，不将不同环境当作一个统一版本。
- 全部纳入结果的任务前后频率门槛通过：至少 10 个负载采样，其中至少 90% 的 SM 频率不低于 1900 MHz。MoE/FA4 个别采样存在 sw_power_cap 和 1875/1897 MHz；不能声称完全没有限频。
- 早期依赖不兼容批次不作为通过结果；FA4 r1 原始归档含未通过的 MHA/varlen 尝试，coverage.json 明确只选其 GQA，MHA/varlen 由后续成功批次替代。
